# Kafra Auto Skjema

Fyller automatisk ut [Gravity Forms](https://www.gravityforms.com/)-felter basert på WooCommerce-produktet brukeren ser på (produktside, variasjon osv.).

**Versjon:** 1.1.8  
**Forfatter:** Benjamin Pedersen

## Krav

- WordPress
- [WooCommerce](https://woocommerce.com/)
- [Gravity Forms](https://www.gravityforms.com/)

## Installasjon

1. Last ned release-zip fra [Releases](https://github.com/bli-synlig-plugins/kafra-auto-skjema/releases), eller klon dette repoet.
2. Legg mappen `kafra-auto-skjema` i `wp-content/plugins/`.
3. Aktiver **Kafra Auto Skjema** under **Plugins**.

## Oppsett

Gå til **WooCommerce → Kafra Auto Skjema**.

1. Velg et Gravity Forms-skjema og legg det til i listen.
2. Kartlegg felter til produktdata (tittel, SKU, attributter, pris m.m.).
3. Plasser skjemaet på produktsider som vanlig (shortcode/block).

Når skjemaet vises i produktkontekst, fylles mappede felter automatisk. Noen felt kan settes som skrivebeskyttet eller forhåndsvalgt (inkl. avkrysningsbokser/flervalg).
